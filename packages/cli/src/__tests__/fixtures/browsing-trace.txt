# Real request trace: distinct hosts each page requested, captured from a live browser session.
#
# Every host below appeared in `performance.getEntriesByType('resource')` for the page named in
# the comment above it, after the page finished loading. Repeats matter: a host listed under two
# pages is two observed uses, which is how the coverage command weights the rules that blocked it.
#
# This is a sample, and a small one: eleven pages from one machine. Read any fired-rule count it
# produces as a floor — the head of a list grows as coverage grows, so a longer or busier session
# touches more hosts and fires more rules. It also records requests as *attempted*: the entries are
# what each page tried to load, and the sandbox this was captured in refused connections to several
# third-party hosts. A refused connection still counts, which is the traffic a network blocker has
# to decide on, so the trace is measured in the units the blocker works in.
#
# Reproduce with:
#   npx --workspace=@blockingmachine/cli blockingmachine coverage \
#     --rules packages/cli/filters/output/genericBrowserRules.txt \
#     --trace packages/cli/src/__tests__/fixtures/browsing-trace.txt
